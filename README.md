# しもへい。LINEシミュレーター

「Ulysses2027 幹部コーチ監督（9人）」で、学習院戦の1週間前に戦術についてしもへい。に返信する、部内向けの非公式ゲームです。今夜中に戦術メモを共有し、次の練習で役割と動きを確認する設定です。

「戦術決まった？」から始まり、3つの返信候補または自由入力で会話が進みます。曖昧な返信には追加の質問が来ます。守備、プレス、ビルドアップ、攻撃、PC、共有まで8つの話題を経て、返信によって結末が変わります。45秒返信しないと催促が来ます（各話題で最大2回、別タブを見ている間は停止）。

最初の返信は、内容にかかわらず「I reject.」「リジェクトされた理由は自分で考えて。」で一度拒否されます。その時点では最初の話題に留まり、再提案すると通常の判定で会話が進みます。

## v0.2 の遊び

- 監督から突然着信。応答すると2つの口頭説明に3択または自由入力で答えます。折り返し・不在着信では、その後の会話と数値が変わります。
- 副将・分析班から個別チャットの通知。副将には役割の確認、下書き、全員への共有、決定事項の確認を頼めます。分析班には映像の根拠を聞けます。
- 戦術メモを編集して提出。合図や守備、共有先が曖昧だと具体的な赤入れが返り、修正して再提出します。提出した各版はトークから確認できます。
- 中盤に3種類の前提変更のどれかが発生。古いメモを使い回すと、最終提出で差し戻されます。
- 通知音・着信音、送信取消、提出版数、通話・幹部協力の結果が会議をにぎやかにします。通知音は画面上で切り替えられます。

通話・資料・個別チャットはすべてゲーム内の演出です。マイク、連絡先、実際のファイルアップロードは使いません。

v0.3では、提供された写真を監督のトーク・入力中・着信アイコンに使い、白いヘッダー、青い背景、白／黄緑の吹き出し、既読と時刻、入力バーをLINEに近い見た目に調整しています。

会話は提供されたログの口調を参考にした創作です。相手の特徴と戦術はゲーム用の仮定であり、実際の試合情報ではありません。元のLINEログ、個人の連絡先、会議URL、他のメンバーの実名は含みません。自由入力の内容は外部へ送信・保存しません。自由入力への反応は話題ごとのキーワードによる判定です。

## 起動

HTML / CSS / JavaScriptのみで動きます。ビルドやAPIキーは不要です。ローカルではこのディレクトリで `python -m http.server 4173` を実行し、`http://localhost:4173` を開いてください。JavaScriptモジュールを使用するため、HTMLの直接ダブルクリックではなくHTTPで開きます。

## GitHub Pages

公開用ファイルをGitHubにpushし、リポジトリの **Settings → Pages → Deploy from a branch** で、公開するブランチと **/(root)** を選択します。GitHub PagesのURLでスマホ・PCから遊べます。`.nojekyll` を含めてください。

## 調整する場所

- `dialogue.js`：しもへい。の台詞、3つの返信候補、話題、自由入力の判定、数値、結末。
- `styles.css`：LINE風の画面、色、余白、スマホ表示。
- `line-ui.css`：トーク一覧・ヘッダー・吹き出し・入力バーのテーマ。
- `assets/shimohei-avatar.png`：提供された監督のアイコン写真。
- `assets/group-avatar.png`：提供されたグループアイコン。
- `index.html`：グループ名・人数・画面のラベル。
- `app.js`：会話表示、入力、既読、入力中表示、催促。
- `events.js`：着信、個別チャット、提出資料の画面と操作。
- `gameplay.js`：突発事件、資料の赤入れ、イベント進行。

検証は `npm test` または `node --test tests/dialogue.test.js tests/gameplay.test.js` で実行できます。外部ライブラリのインストールは不要です。

着想元：[コンサル詰めシミュレーター](https://landsknecht.jp/tsume/)。画面・コード・会話は独自実装です。LINE公式とは関係ありません。
